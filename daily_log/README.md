## 🛠 Hướng Dẫn Thêm Ngày Mới
Khi bắt đầu một ngày làm việc mới:
1. Sao chép nội dung từ file [TEMPLATE.md](TEMPLATE.md).
2. Tạo file mới theo định dạng: `daily_log/YYYY-MM-DD.md` (ví dụ: `2026-09-15.md`).
3. Điền các mục tiêu, tiến độ, vấn đề gặp phải và cập nhật lại bảng danh sách ở file này.
